## 上线验收步骤

1. **首次使用**：清洁浏览器来源联网进入，确认 100 题、10 课和默认语速；等待离线准备完成。首次断网进入未安装过的来源应显示重试说明。
2. **练习保存**：答错一题、答对一题，刷新和关闭重开，计数与错题保留；快速双击不能记两次。完成 20 题后更新课程或切换模式也不能继续计分。
3. **离线冷启动**：等离线准备完成后开飞行模式，关闭浏览器再从主屏幕进入，练习、课程、统计、备份可用；外部资源提示需联网。
4. **间隔复习**：使用独立测试来源和测试备份模拟昨天错题到期、1 天和 3 天间隔、第三次掌握。不要修改正式学习数据或系统时间测试。
5. **课程成功更新**：按发布文档增加新题，旧客户端检查更新，确认新题出现、旧 ID 的掌握情况与当天计数不变。
6. **课程失败更新**：在测试分支发布不存在地址或错误摘要，旧客户端显示失败并继续使用旧课程；修复后可再更新。
7. **程序更新**：先安装旧 SW，再发布更高 `APP_VERSION`；旧页面出现提示，点击后新样式生效，记录不变。新资源 404 时旧程序应继续可用。
8. **导入导出**：导出 V3，换浏览器导入；导入 V2；坏 JSON、负数、重复 ID 不得改变现有记录。导入正确文件后需点击页面确认。
9. **多标签**：两个同源标签依次答题，计数同步；同一题同时提交仅计一次。确认目标浏览器支持 Web Locks，旧版本避免多标签同时练习。
10. **安装与朗读**：分别在 Android Chrome、三星浏览器安装到主屏幕，测试 0.5 / 0.85 / 1.25 倍速、重复和停止；安装英语本地语音后断网测试朗读。
11. **设备布局与键盘**：360px 手机宽、桌面宽度、放大字体，检查无横向溢出；Tab 可到达按钮，空格、1、2、R 生效。
12. **生产响应头**：浏览器开发工具检查清单为 `no-store`、SW 不长期缓存、CSP 无意外拦截。确保使用固定生产域名。
